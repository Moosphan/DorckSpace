# P1-01 研究素材库实施计划

## 目标

建立本地优先的研究素材记录，使 RSS 收藏、书摘和手动记录可以安全地保留来源，并关联到项目和文章。

## 技术边界

- SQLite 数据与关联操作全部在主进程。
- 渲染层只读取已规范化的素材 DTO，不暴露 RSS 原始响应或浏览器登录态。
- 使用来源类型与来源 ID 实现幂等转换；手动素材没有来源 ID。
- 关联删除时置空关联字段，素材及其外部来源仍保留。

## 执行步骤

1. 新增失败测试，覆盖 RSS 转素材、重复转换幂等、项目/文章关联和上下文检索。
2. 增加 `research_materials` migration、Repository 与 IPC。
3. 在 Research 与 Highlights 弹窗增加“加入素材库”操作。
4. 新增 Research Library 弹窗，并在 Writing Studio 增加入口。
5. 扩展统一搜索与 URL 参数直达。
6. 运行专项测试、类型检查、lint、构建及应用；等待确认后提交。
