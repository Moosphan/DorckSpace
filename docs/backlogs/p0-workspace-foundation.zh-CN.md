# P0 可信工作台 Backlog

> 目标：让 MyDashboard 的首页、数据和本地存储可以被日常依赖。
> 执行规则：每个任务独立测试、运行应用、人工确认、提交；未确认前不进入下一项。

## P0-01 真实活动统计与热力图

**价值**：首页活动不再是 mock；完成任务、编辑文章等真实行为能沉淀为工作轨迹。

**范围**

- 增加 ActivityLogRepository 和 activity:getRecent IPC。
- 将任务状态变更、文章内容保存写入当日活动聚合。
- ActivityHeatmap 读取最近 28 天真实活动并显示空状态。
- 保持现有 activity_log 的日期和活动类型唯一约束。

**验收**：无活动时显示“暂无活动”；完成任务或保存文章后刷新首页能看到强度变化；数据不依赖 mock 常量。

**状态**：Ready

## P0-02 Dashboard 今日工作台

**价值**：打开应用即可确认焦点项目、今天任务、逾期任务、最近产出和下一步行动。

**范围**：增加 dashboard:getTodayOverview 聚合 IPC；焦点项目展示里程碑、完成率和阻塞项；今日任务按逾期、高优先级、截止时间排序；最近产出可直接打开。

**验收**：有数据时无占位文案；无焦点项目时有设置入口；今日、逾期和完成态均有空状态。

**状态**：Blocked by P0-01

## P0-03 项目、任务、里程碑闭环

**价值**：项目进度反映真实任务完成情况，而非孤立的手动百分比。

**范围**：统一完成任务、里程碑和取消任务的进度规则；任务支持关联里程碑；焦点项目显示下一里程碑和阻塞项；项目管理弹窗显示概览。

**验收**：任务状态变化后项目进度一致更新；里程碑任务完成后可达成；删除实体后不存在悬挂关联。

**状态**：Blocked by P0-02

## P0-04 统一搜索与上下文操作

**价值**：通过 Cmd+K 找到任意个人资料并完成下一步操作。

**范围**：覆盖项目、任务、文章、RSS、书摘、灵感、视频资产和热门内容；先使用安全 LIKE 查询和统一排序；支持打开、完成、收藏、加入素材库和查看来源。

**验收**：结果标示类型、来源和更新时间；空关键词不访问数据库；不返回 provider 原始敏感响应。

**状态**：Blocked by P0-03

## P0-05 本地备份、安全与恢复

**价值**：用户能安全带走和恢复个人数据，不担心 API Key 与会话信息泄露。

**范围**：SQLite 一致性备份；数据库、文章和媒体归档；manifest 校验；恢复前备份和失败回滚；safeStorage 加密 API Key；日志脱敏。

**验收**：备份可恢复并通过 schema 校验；损坏 manifest 不覆盖现有数据；日志不存在 Cookie、Token、Authorization 或 API Key 明文。

**状态**：Ready after P0-01

## P0-06 后台刷新、来源健康与通知

**价值**：RSS、热门内容和 Reset Radar 可持续工作，失败原因可诊断。

**范围**：统一报告 ok、warn、stale、error、fixture；超时、退避、TTL 和并发保护；新文章、任务到期和高置信 Reset Radar 信号去重与静默；显示来源采样状态。

**验收**：provider 失败不阻塞启动；重复通知在静默窗口内被抑制；fixture 在生产运行中显式标识。

**状态**：Ready after P0-01

## 执行顺序

1. P0-01：真实活动统计与热力图。
2. P0-02：Dashboard 今日工作台。
3. P0-03：项目、任务、里程碑闭环。
4. P0-04：统一搜索与上下文操作。
5. P0-05：本地备份、安全与恢复。
6. P0-06：后台刷新、来源健康与通知。
