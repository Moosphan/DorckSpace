# MyDashboard 产品路线与功能优先级

> 更新日期：2026-08-28
> 定位：本地优先的个人工作与创作操作系统

## 1. 产品结论

MyDashboard 不应发展为另一个待办应用、Notion 替代品或通用 AI 聊天壳。核心价值是把个人开发者和内容创作者分散的工作流收敛为可执行、可追溯、可复盘的本地闭环：

项目目标 → 任务执行 → 信息收集 → 知识沉淀 → 内容创作
→ 多平台发布 → 数据回流 → 下一轮选题和项目决策

当前代码已经具备项目、任务、里程碑、写作、素材、RSS、热门内容、内置浏览器、AI 用量和 Reset Radar 的基础。最大的缺口不是页面数量，而是：

- 首页尚未成为“今天该做什么”的行动入口。
- 活动热力图和部分外部数据缺少真实来源与健康状态，影响信任。
- 文章、书摘、RSS、灵感和媒体素材尚未进入统一知识链路。
- 发布后的平台数据没有稳定回流到选题和项目决策。
- AI 能力尚未获得完整的个人上下文，也没有受控执行边界。

## 2. 当前能力判断

### 已有且可复用

- Electron、React、TypeScript、SQLite 和本地文件存储的分层架构。
- 项目、任务、焦点项目、任务看板和里程碑数据能力。
- Tiptap 编辑、文章 CRUD、书摘、高亮、收藏和发布辅助。
- RSS、社交账号指标、热门内容 provider、缓存和健康状态基础。
- AI 订阅、Token 用量、内置浏览器、ChatGPT 会话和 Reset Radar。
- Module Registry、Extension Point 与 Module Loader 插件基础设施。

### 需要优先消除

- 首页活动热力图仍是 mock 数据，不能反映真实工作量。
- 首页缺少项目目标、里程碑、阻塞和下一步行动。
- 全局搜索没有统一覆盖所有个人实体，也缺少上下文操作。
- 本地优先产品缺少完整备份、恢复和数据可移植闭环。
- 外部 provider 的实时、缓存、过期、fixture 和失败状态需要明确呈现。
- Reset Radar 仍需要可靠调度、通知和来源诊断。

## 3. 开源项目借鉴边界

| 项目 | 可借鉴 | 不建议照搬 |
| --- | --- | --- |
| AppFlowy | 统一工作区、结构化数据库、多视图项目管理 | 团队协作和 Notion 替代范围 |
| AFFiNE | 页面、数据库、知识关联和 AI 入口 | 大型自由画布和实时协同 |
| Logseq | 本地文件、双向链接、块级引用 | 早期完整知识图谱 |
| Khoj | 本地索引、RAG、定时研究任务 | 过早引入复杂 Agent 编排 |
| Super Productivity | 任务执行、时间盒、项目上下文 | 全面的外部任务同步 |
| gAIOS | 确定性工具、验证流程、受控 Agent | 通用多 Agent 操作系统 |

## 4. 优先级路线

### P0：可信工作台基础

1. 真实活动统计与热力图。
2. Dashboard 今日工作台：焦点项目、里程碑、今日任务、逾期项、最近产出和下一步行动。
3. 项目、任务、里程碑闭环：进度推导、阻塞提示、项目上下文关联。
4. 统一搜索：覆盖项目、任务、文章、RSS、书摘、素材和热门内容。
5. 本地备份、恢复、安全存储和日志脱敏。
6. 后台刷新、Provider 健康和通知基础设施，包含 Reset Radar 来源诊断。

### P1：知识与内容增长闭环

1. 本地知识库和素材库，统一文章、链接、书摘、RSS、灵感、图片和代码片段。
2. 收藏内容、书摘和 RSS 文章一键转研究素材，并与项目和文章双向关联。
3. 基于个人资料和来源引用的 AI 研究助手与语义搜索。
4. 素材到大纲、文章、多平台版本、发布记录的 AI 内容生产线。
5. 平台发布回执、指标快照和跨平台内容复盘。
6. 时间盒、专注模式、任务预估与实际耗时统计。
7. 受控 AI Agent：先提供可预览、可确认、可审计的低风险自动化。

### P2：扩展与平台化

- 视频生产闭环：音频预览、HTML PPT 预览、配音、视频导出和分发记录。
- 自动日报、周报和项目复盘。
- Reset Radar 高置信度通知、多来源权重和结构化 AI 解释。
- Dashboard Widget、插件 SDK、Ollama 和本地模型。

### P3：暂缓项

- 多人实时协作、完整自由画布和复杂知识图谱。
- 全平台无人值守自动发布。
- 通用多 Agent 编排平台。
- 与核心工作流无关的生活、健康或财务追踪。

## 5. 实施阶段与指标

| 阶段 | 目标 | 完成标志 |
| --- | --- | --- |
| Phase 0 | 稳定性与真实数据 | 首页不展示 mock 工作数据；provider 可诊断；数据可恢复 |
| Phase 1 | 个人工作闭环 | 打开首页能明确下一步，并能从项目推进到任务完成 |
| Phase 2 | 知识与 AI 上下文 | 收藏和阅读内容可检索、关联并被 AI 引用 |
| Phase 3 | 内容增长闭环 | 素材能成为发布内容，发布效果能回流复盘 |
| Phase 4 | 自动化与生态 | Agent 与插件可安全、可审计扩展 |

北极星指标：

- 打开 Dashboard 后确认下一步行动的耗时。
- 项目任务按时完成率与逾期任务数量。
- 从收藏素材到形成可发布文章的耗时。
- 已发布内容的平台数据回流覆盖率。
- 外部数据源真实成功率、缓存命中率和 fixture 使用率。
- AI 建议采纳率及每次建议可追溯的来源数量。

## 6. 最终推荐 Top 5

1. Dashboard 今日工作台与项目、任务、里程碑闭环。
2. 本地知识库、素材库与统一搜索。
3. 基于来源引用的 AI 研究助手和内容生产线。
4. 真实发布回执与跨平台数据分析。
5. 稳定性、备份、安全、通知和数据源健康体系。
